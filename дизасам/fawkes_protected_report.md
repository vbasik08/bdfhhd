# Отчёт по 35-МБ Fawkes (что реально внутри)

Файл: `F:\imgeneus develep\клиенты\ShaiyaFawkes\Shaiya\default\game\game.exe`

## Что выяснилось
- Заголовок PE испорчен: EntryPoint `02841600` вне образа, имена секций мусорные (`cyayitzp`, `PE_ADS`), image base `00400000`.
- Большая секция объявлена как 33 280 000 байт, но **реального содержимого ~4,6 МБ** (`00401000`–`00865409`); остальные **~28 МБ — нули**.
- В этой области ~21 500 строк, 12 501 функция (по прологам и целям `call`), 73 166 прямых вызовов, 1 418 вызовов WinAPI через IAT.
- «99,95% валидных байт» из первой оценки — артефакт: нули стабильно декодируются как `add [eax], al`. Корректный вывод: файл — усечённый/дамп-подобный образ, код читается, хвост пустой.

## Как это влияет
- Дизассемблировать имеет смысл только область `00401000`–`00865409` — это и сделано (`fawkes_game_text.asm`, 52.9 МБ).
- Адреса = image_base + RVA.
